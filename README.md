
# 🏪 Nova-Store
مشروع متجر إلكتروني متكامل يركز على تجربة المستخدم والأداء العالي.
## 🚀 المميزات
* **تصميم متجاوب:** يعمل بسلاسة على كافة الشاشات (Mobile, Tablet, Desktop).
* **واجهة عصرية:** استخدام أحدث تقنيات CSS لضمان جاذبية بصرية.
* **الأداء:** كود نظيف وسريع التحميل.
## 🛠️ التقنيات المستخدمة
* **HTML5 & CSS3**
* **Git & GitHub** للنشر والإدارة.
